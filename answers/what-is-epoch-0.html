What Is Epoch 0?

Epoch 0 is January 1, 1970, 12:00:00 AM UTC (Thursday) — the Unix epoch.

What Does Epoch 0 Mean?

Epoch 0 is the origin of Unix time. All Unix timestamps are measured as the number of seconds before or after this exact moment: midnight on January 1, 1970, Coordinated Universal Time (UTC). In ISO 8601 format, this is 1970-01-01T00:00:00Z.

The Unix epoch was chosen by the creators of Unix at Bell Labs. It was a round, recent date at the time Unix was being developed in the late 1960s. Today, virtually every computer system uses this same reference point for time.
