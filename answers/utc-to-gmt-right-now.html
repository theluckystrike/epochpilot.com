Understanding the UTC to GMT Offset

UTC (Coordinated Universal Time) has a UTC offset of UTC+0. GMT (Greenwich Mean Time) has a UTC offset of UTC+0. The net difference between these two zones is 0 hours. When it is noon in UTC, it is 12:00 PM in GMT.

Daylight saving time note: UTC does not observe DST. GMT observes DST (becomes BST, UTC+1). During DST periods, the offset between these zones may change by 1 hour. The table below shows standard time offsets.

The IANA timezone identifiers for these zones are UTC (UTC) and Europe/London (GMT). These identifiers are used by programming languages and operating systems to handle timezone conversions correctly, including automatic DST adjustments.

Code Examples

Python

from datetime import datetime
from zoneinfo import ZoneInfo

# Current time in UTC
now_from = datetime.now(ZoneInfo("UTC"))
# Convert to GMT
now_to = now_from.astimezone(ZoneInfo("Europe/London"))
print(f"UTC: {now_from.strftime('%I:%M %p')}")
print(f"GMT: {now_to.strftime('%I:%M %p')}")

JavaScript

// Convert current time from UTC to GMT
const now = new Date();
const from = now.toLocaleString("en-US", { timeZone: "UTC" });
const to = now.toLocaleString("en-US", { timeZone: "Europe/London" });
console.log("UTC:", from);
console.log("GMT:", to);

Go

package main

import (
    "fmt"
    "time"
)

func main() {
    fromLoc, _ := time.LoadLocation("UTC")
    toLoc, _ := time.LoadLocation("Europe/London")
    now := time.Now().In(fromLoc)
    converted := now.In(toLoc)
    fmt.Printf("UTC: %s\n", now.Format("3:04 PM"))
    fmt.Printf("GMT: %s\n", converted.Format("3:04 PM"))
}

Frequently Asked Questions

What is the time difference between UTC and GMT?

UTC (Coordinated Universal Time) is UTC+0 and GMT (Greenwich Mean Time) is UTC+0. The standard time difference is 0 hours.

Does daylight saving time affect the UTC to GMT conversion?

No, UTC does not observe DST. GMT observes DST and shifts to BST (UTC+1) during summer months. Always use IANA timezone identifiers in code to automatically handle these transitions.

What are the best overlap hours for UTC and GMT meetings?

For scheduling meetings between UTC and GMT, look for hours when both zones are in typical business hours (9 AM to 5 PM). When it is 9:00 AM in UTC, it is 9:00 AM in GMT. When it is 5:00 PM in UTC, it is 5:00 PM in GMT. The best overlap window depends on the specific zones and whether DST is active.
