# EpochPilot

> Free epoch and Unix timestamp converter, timezone tools, cron expression parser, and date calculators for developers.

**[Use EpochPilot live](https://epochpilot.com/)**

EpochPilot is a browser-based suite of 30+ time and timestamp tools for developers. Convert Unix timestamps to human-readable dates, compare timezones with full IANA database support, build and parse cron expressions, calculate date differences, and look up timestamp syntax across every popular programming language. Everything runs locally — no data is sent to any server.

## Features

- Unix epoch to human-readable date converter with auto-format detection (seconds and milliseconds)
- Bidirectional date-to-epoch conversion supporting ISO 8601, RFC 3339, and custom formats
- Full IANA timezone database with daylight saving time handling
- Visual cron expression builder with 10 preset templates and next-run preview
- Cron-to-English translator and interactive crontab reference
- Date arithmetic: days between dates, business days, add/subtract days, age calculator
- Language-specific timestamp references for JavaScript, Python, Java, PHP, and Go
- Live UTC and local clocks updating in real time
- 100% client-side — no data leaves your browser
- MIT licensed
- No signup, no tracking
